# PRD - Color Picker Saturation Refinement

## Goal
Standardize the visual intensity of the spatial color picker rings to create a more balanced and professional UI.

## Requirements
- **Ring Saturation**: Both the middle (`ringInner`) and large (`ringOuter`) color rings must have their saturation set to exactly 60.
- **Visual Consistency**: Ensure the lightness remains appropriate for visibility while the saturation is lowered.

## User Experience
- The color picker spatial section feels more cohesive and less visually overwhelming.
- Consistent saturation levels make the rings feel like part of the same system.
