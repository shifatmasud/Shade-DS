# Framer Canvas Component Types Reference

This reference documents the default DOM architectures, selector patterns, and layer hierarchies generated by Framer for standard canvas component primitives.

---

## 1. Component Types & DOM Hierarchies

### 1. Path (SVG Component)
Framer renders vector paths wrapped in a container `div` marked with `data-framer-component-type="SVG"`. The actual SVG references a symbol definition or path element inside its subtree.

- **DOM Structure:**
  ```html
  <div data-framer-component-type="SVG" data-framer-name="Child 1">
      <div class="svgContainer">
          <svg>
              <use href="#svg-1414304237_256"></use>
          </svg>
      </div>
  </div>
  ```
- **Primary Selector:** `div[data-framer-component-type="SVG"][data-framer-name="..."]`
- **Target Child Elements:** `div.svgContainer`, `svg`, `use`

---

### 2. Vector Set
A direct SVG element rendered at the component level without a wrapper `div`.

- **DOM Structure:**
  ```html
  <svg data-framer-name="Child 2">
      <use href="#1697384173"></use>
  </svg>
  ```
- **Primary Selector:** `svg[data-framer-name="..."]`
- **Target Child Elements:** `use[href]`

---

### 3. Image
Framer renders images wrapped in a background image wrapper container.

- **DOM Structure:**
  ```html
  <div data-framer-name="Child 3">
      <div data-framer-background-image-wrapper="true">
          <img src="https://framerusercontent.com/images/..." alt="" />
      </div>
  </div>
  ```
- **Primary Selector:** `div[data-framer-name="..."]`
- **Target Child Elements:** `div[data-framer-background-image-wrapper]`, `img[src]`

---

### 4. Video
Framer renders video layers with an inner `<video>` tag.

- **DOM Structure:**
  ```html
  <div data-framer-name="Child 5">
      <video src="...mp4" playsinline autoplay loop muted></video>
  </div>
  ```
- **Primary Selector:** `div[data-framer-name="..."]`
- **Target Child Elements:** `video[src]`

---

### 5. Text (Rich Text Container)
Text layers in Framer are outputted inside a container marked with `data-framer-component-type="RichTextContainer"`. Paragraphs and nested spans contain the individual characters or tokens.

- **DOM Structure:**
  ```html
  <div data-framer-name="Child 4" data-framer-component-type="RichTextContainer">
      <p>
          #text "T"
          <span>#text "e"</span>
          <span>#text "x"</span>
          <span>#text "t"</span>
      </p>
  </div>
  ```
- **Primary Selector:** `div[data-framer-name="..."][data-framer-component-type="RichTextContainer"]`
- **Target Child Elements:** `p`, `span`, `h1`-`h6`, text nodes (`nodeType === Node.TEXT_NODE`)

---

## 2. Complete Framer DOM Tree Map

```text
div [data-framer-root]
    └── div [data-framer-name="Parent"]
        ├── div [data-framer-component-type="SVG"][data-framer-name="Child 1"]
        │   └── div.svgContainer
        │       └── svg
        │           └── use [href="#svg-1414304237_256"]
        ├── svg [data-framer-name="Child 2"] // Vector Set
        │   └── use [href="#1697384173"]
        ├── div [data-framer-name="Child 3"]
        │   └── div [data-framer-background-image-wrapper]
        │       └── img [src="https://framerusercontent.com/images/..."]
        ├── div [data-framer-name="Child 5"]
        │   └── video [src="...mp4"]
        └── div [data-framer-name="Child 4"][data-framer-component-type="RichTextContainer"]
            └── p
                ├── #text "T"
                ├── span
                │   └── #text "e"
                ├── span
                │   └── #text "x"
                └── span
                    └── #text "t"
```

---

## 3. Framer Canvas vs. DOM Mapping

| Canvas Layer Type | DOM Element Tag | Identifying Attribute / Structure |
| :--- | :--- | :--- |
| **Path (SVG)** | `div` > `div.svgContainer` > `svg` | `[data-framer-component-type="SVG"]` |
| **Vector Set** | `svg` | Tag is `svg` directly + `[data-framer-name]` |
| **Image** | `div` > `div` > `img` | `[data-framer-background-image-wrapper]` inside wrapper |
| **Video** | `div` > `video` | Nested `video` element inside wrapper |
| **Text** | `div` > `p` > `span` / text | `[data-framer-component-type="RichTextContainer"]` |
| **Frame** | `div` | Layout container (no specific `component-type` attribute) |

---

## 4. Discovery & Extraction Utility Patterns

```typescript
export type FramerCanvasComponentType = 
    | "SVG" 
    | "VectorSet" 
    | "Image" 
    | "Video" 
    | "RichText" 
    | "Frame" 
    | "Unknown";

export function identifyFramerComponent(element: HTMLElement | SVGElement): {
    type: FramerCanvasComponentType;
    targetNode: HTMLElement | SVGElement | null;
} {
    const compType = element.getAttribute("data-framer-component-type");

    // 1. Path (SVG Component)
    if (compType === "SVG") {
        const svg = element.querySelector("svg");
        return { type: "SVG", targetNode: svg || element };
    }

    // 2. Vector Set (Direct SVG)
    if (element.tagName.toLowerCase() === "svg") {
        return { type: "VectorSet", targetNode: element };
    }

    // 3. Text (RichTextContainer)
    if (compType === "RichTextContainer" || element.querySelector("p, span, h1, h2, h3, h4, h5, h6")) {
        const textContainer = element.querySelector("p") || element;
        return { type: "RichText", targetNode: textContainer as HTMLElement };
    }

    // 4. Image
    const imgWrapper = element.querySelector("[data-framer-background-image-wrapper]");
    const img = element.querySelector("img");
    if (imgWrapper || img) {
        return { type: "Image", targetNode: (img || imgWrapper || element) as HTMLElement };
    }

    // 5. Video
    const video = element.querySelector("video");
    if (video) {
        return { type: "Video", targetNode: video };
    }

    // Default: Layout Frame
    return { type: "Frame", targetNode: element as HTMLElement };
}
```
