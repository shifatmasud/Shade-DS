# esm.sh Query Parameters & Configuration Matrix

This reference outlines the full suite of query parameters and syntax features provided by `esm.sh` and their specific application within Framer code components.

---

## 1. Parameter Specifications

| Parameter | Syntax Example | Functional Behavior | Required Context in Framer |
| :--- | :--- | :--- | :--- |
| `external` | `?external=react,react-dom` | Prevents the CDN from bundling the specified modules. Generates standard `import ... from "react"` statements inside the bundle. | **Mandatory** for any package consuming React hooks, JSX, or components (e.g., `@gsap/react`, `lucide-react`, `@react-three/fiber`). |
| `target` | `?target=es2022` | Controls the JavaScript syntax level generated by esbuild (e.g., `es2020`, `es2021`, `es2022`, `esnext`). | Useful when older browser engines or headless engines need simplified syntax. |
| `bundle` | `?bundle` | Bundles all non-external sub-dependencies into one cohesive JavaScript payload. | Reduces latency when importing libraries with hundreds of small files. |
| `deps` | `?deps=three@0.183.2` | Forces transitive dependencies to resolve to an exact pinned version. | Prevents duplicate versions when combining addons with core libraries. |
| `alias` | `?alias=lodash:lodash-es` | Remaps internal module specifiers. | Resolving legacy CommonJS references to ESM equivalents. |
| `dev` | `?dev` | Compiles in development mode, enabling unminified error messages and React DevTools hooks. | Debugging rendering issues or property control discrepancies. |
| `no-dts` | `?no-dts` | Omits the `X-TypeScript-Types` HTTP header. | Optimizes transfer size if types are not required by the client. |
| `css` | `?css` | Injects package stylesheets directly. | Loading component UI styles (e.g. Prism themes, Katex math styling). |

## 2. Common NPM Package Configurations for Framer

### Three.js & 3D Shaders
```tsx
// Core Three.js pinned version
import * as THREE from "https://esm.sh/three@0.186.0"

// Addons & Geometries (pinned to match core version)
import { RoundedBoxGeometry } from "https://esm.sh/three@0.186.0/addons/geometries/RoundedBoxGeometry.js"
import { OrbitControls } from "https://esm.sh/three@0.186.0/addons/controls/OrbitControls.js"
```

### GSAP & Animation
```tsx
// GSAP Core
import { gsap } from "https://esm.sh/gsap@3.12.5"

// GSAP React Hook (MUST externalize react)
import { useGSAP } from "https://esm.sh/@gsap/react?external=react"

// GSAP Plugins
import { SplitText } from "https://esm.sh/gsap/SplitText"
import { ScrollTrigger } from "https://esm.sh/gsap/ScrollTrigger"
```

### Icons & UI Utilities
```tsx
// Lucide React Icons (MUST externalize react, react-dom)
import { Sparkles, ArrowRight, Check } from "https://esm.sh/lucide-react@0.469.0?external=react,react-dom"

// Canvas Confetti
import confetti from "https://esm.sh/canvas-confetti@1.9.3"

// Color & Math Libraries
import chroma from "https://esm.sh/chroma-js@3.1.2"
import SimplexNoise from "https://esm.sh/simplex-noise@4.0.3"
```
