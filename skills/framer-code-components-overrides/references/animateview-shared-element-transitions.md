# Shared Element Page Transitions with `animateView`

This reference covers implementing seamless **Shared Element Morphing** and **Page Transitions** between routes in Framer (e.g., from `demo.framer.website` to `demo.framer.website/blog/new-item`) using Framer Motion's `animateView` function combined with the **Parasitic DOM Binding** pattern.

---

## 1. Mental Model & Architecture

When navigating between routes or views:
1. **Shared Elements**: Specific elements (e.g., a thumbnail card on the list page and the hero header on the blog post page) morph their position, scale, and border-radius smoothly from the old snapshot to the new snapshot.
2. **Non-Shared Elements**: All other elements on the outgoing page crossfade out, blur, and slide up gently; incoming page elements crossfade in, unblur, and settle into place.
3. **Parasitic Binding**: The transition controller is dropped into the canvas as an invisible or lightweight injector, binding parasitically to its `parent`, `grandparent`, or `sharedParent` siblings without requiring intrusive prop-drilling.

```
┌────────────────────────────────────────────────────────────────────────┐
│ Old Page (demo.framer.website)                                         │
│                                                                        │
│  [ Header / Nav ]  (Non-shared) ──► Crossfade out + Blur + Slide Up   │
│                                                                        │
│  ┌───────────────────────┐                                             │
│  │ Shared Card Thumbnail │ ───────┐ (Morphs via .add(from, to))        │
│  └───────────────────────┘        │                                    │
└───────────────────────────────────┼────────────────────────────────────┘
                                    │  animateView(update, transition)
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│ New Page (demo.framer.website/blog/new-item)                           │
│                                                                        │
│  ┌─────────────────────────────────────────────────────────────┐       │
│  │ Full Shared Hero Image                                      │       │
│  └─────────────────────────────────────────────────────────────┘       │
│                                                                        │
│  [ Article Body & Details ] (Non-shared) ──► Crossfade in + Unblur     │
└────────────────────────────────────────────────────────────────────────┘
```

## 2. Core `animateView` API Reference

`animateView` is Framer Motion's high-level orchestrator built on top of View Transitions. It captures DOM snapshots before and after a state or route mutation, allowing precise choreography of shared elements and full-page surfaces.

### Basic Syntax

```typescript
import { animateView } from "framer-motion"

const transition = animateView(updateFn, {
    type: "spring",
    stiffness: 350,
    damping: 30,
    mass: 1,
})
```

### 1. Morphing Shared Elements (`.add`)

Register pairs of DOM elements to morph between the old snapshot and the new snapshot:

```typescript
// Register DOM element pair
transition.add(fromElement, toElement)

// Or specify individual transition overrides per shared element
transition.add(fromElement, toElement, {
    duration: 0.6,
    ease: [0.16, 1, 0.3, 1],
})
```

### 2. Customizing Non-Shared Old & New Page Snapshots (`.old` and `.new`)

Style the outgoing (`.old`) snapshot and incoming (`.new`) snapshot:

```typescript
// Crossfade, blur, and gentle upward slide
transition
    .old({
        opacity: 0,
        filter: "blur(8px)",
        y: -24,
    })
    .new({
        opacity: 1,
        filter: "blur(0px)",
        y: 0,
    })
```

### 3. Integrating with Framer `ControlType.Transition`

`animateView` accepts the exact transition options generated by Framer's `ControlType.Transition` control:

```typescript
import { addPropertyControls, ControlType } from "framer"

export default function SharedTransitionComponent(props) {
    const { transitionConfig } = props

    const handleNavigate = () => {
        animateView(async () => {
            // Apply DOM mutation or route navigation
            await performNavigation()
        }, transitionConfig)
            .add(fromEl, toEl)
            .old({ opacity: 0, filter: "blur(6px)", y: -16 })
            .new({ opacity: 1, filter: "blur(0px)", y: 0 })
    }

    return null
}

addPropertyControls(SharedTransitionComponent, {
    transitionConfig: {
        type: ControlType.Transition,
        title: "Transition",
        defaultValue: {
            type: "spring",
            stiffness: 300,
            damping: 28,
            mass: 0.8,
        },
    },
})
```

## 3. Parasitic DOM Discovery & Binding

To avoid hardcoding references, use the **Parasitic DOM Binding** pattern. The component attaches to its host container and resolves trigger elements and shared targets based on `bindMode`.

### Binding Modes

| Mode | Lookup Strategy | Best Used For |
| :--- | :--- | :--- |
| `parent` | `ref.current.parentElement` | Dropped directly inside a clickable Card Frame |
| `grandparent` | `ref.current.parentElement?.parentElement` | Dropped inside a nested graphic or wrapper inside the Card |
| `shared-parent` | Climbs until finding multi-child container, scans siblings | Placed alongside a list of cards or sibling frames |
| `custom-selector` | Queries `document.querySelector(selector)` | Global page-level targeting |

### Parasitic Host Hook Implementation

```typescript
import { useLayoutEffect, useState, type RefObject } from "react"

export type BindMode = "parent" | "grandparent" | "shared-parent" | "custom-selector"

export function useParasiticHost(
    ref: RefObject<HTMLElement>,
    mode: BindMode = "parent",
    customSelector?: string
): HTMLElement | null {
    const [host, setHost] = useState<HTMLElement | null>(null)

    useLayoutEffect(() => {
        const el = ref.current
        if (!el || typeof window === "undefined") return

        let target: HTMLElement | null = null

        switch (mode) {
            case "parent":
                target = el.parentElement
                break
            case "grandparent":
                target = el.parentElement?.parentElement ?? null
                break
            case "shared-parent": {
                let current: HTMLElement | null = el.parentElement
                while (current && current !== document.body) {
                    if (current.children.length > 1) {
                        target = current
                        break
                    }
                    current = current.parentElement
                }
                break
            }
            case "custom-selector":
                if (customSelector) {
                    target = document.querySelector(customSelector) as HTMLElement | null
                }
                break
        }

        setHost(target)
    }, [mode, customSelector])

    return host
}
```

## 4. Browser Navigation, URL & History API Handling

In Framer websites, navigations can occur via native `<a>` tags, Framer router links, or SPA route transitions.

### Navigation Interception Recipe

When a user clicks on the small card to navigate from `demo.framer.website` to `demo.framer.website/blog/new-item`:

1. **Find From-Element**: Identify the shared element inside the clicked card using a shared key or data attribute (e.g., `data-shared-id="blog-cover"`).
2. **Execute Navigation Inside `animateView`**:
   - Push new URL via `window.history.pushState({}, "", targetUrl)`.
   - Trigger the DOM swap (e.g., via Framer's internal router, fetching HTML snapshot, or switching route state).
   - Resolve the matching `toElement` on the incoming DOM tree.
3. **Trigger Transition**: `animateView` smoothly transforms `fromElement -> toElement` while applying crossfade, blur, and upward slide to the rest of the document.

```typescript
async function navigateWithSharedTransition({
    targetUrl,
    fromElement,
    sharedSelector,
    transitionOptions,
    blurAmount = 8,
    slideDistance = 20,
}: {
    targetUrl: string
    fromElement: HTMLElement
    sharedSelector: string
    transitionOptions?: any
    blurAmount?: number
    slideDistance?: number
}) {
    if (typeof window === "undefined") return

    // 1. Initiate Framer Motion animateView transition
    const viewTransition = animateView(async () => {
        // 2. Update Browser URL
        window.history.pushState({ path: targetUrl }, "", targetUrl)

        // 3. Dispatch navigation/popstate event so Framer router mounts the new page
        window.dispatchEvent(new PopStateEvent("popstate", { state: { path: targetUrl } }))

        // Wait a frame for the new DOM to render
        await new Promise((resolve) => requestAnimationFrame(resolve))

        // 4. Discover the matching target element in the new view
        const toElement = document.querySelector(sharedSelector) as HTMLElement | null

        if (fromElement && toElement) {
            viewTransition.add(fromElement, toElement)
        }
    }, transitionOptions)

    // 5. Choreograph non-shared outgoing and incoming view surfaces
    viewTransition
        .old({
            opacity: 0,
            filter: `blur(${blurAmount}px)`,
            y: -slideDistance,
        })
        .new({
            opacity: 1,
            filter: "blur(0px)",
            y: 0,
        })

    return viewTransition
}
```

## 5. Complete Production Code Component

Save this component as `SharedElementPageTransition.tsx` to use directly on the Framer canvas.

```tsx
/**
 * @framerDisableUnlink
 * @framerIntrinsicWidth 120
 * @framerIntrinsicHeight 40
 */
import type { ComponentType } from "react"
import { useRef, useEffect, useState } from "react"
import { motion, animateView } from "framer-motion"
import { addPropertyControls, ControlType, RenderTarget } from "framer"

interface Props {
    targetUrl: string
    bindMode: "parent" | "grandparent" | "shared-parent" | "selector"
    customSelector: string
    sharedSelector: string
    blurAmount: number
    slideDistance: number
    transition: any
    enabledOnCanvas: boolean
}

export default function SharedElementPageTransition(props: Props) {
    const {
        targetUrl = "/blog/new-item",
        bindMode = "parent",
        customSelector = "",
        sharedSelector = "[data-shared-element]",
        blurAmount = 8,
        slideDistance = 20,
        transition = {
            type: "spring",
            stiffness: 350,
            damping: 30,
            mass: 0.9,
        },
        enabledOnCanvas = false,
    } = props

    const containerRef = useRef<HTMLDivElement | null>(null)
    const [isClient, setIsClient] = useState(false)
    const isOnCanvas = RenderTarget.current() === RenderTarget.canvas

    useEffect(() => {
        setIsClient(true)
    }, [])

    useEffect(() => {
        if (!isClient) return
        if (isOnCanvas && !enabledOnCanvas) return

        const el = containerRef.current
        if (!el) return

        // 1. Resolve host element based on bindMode
        let host: HTMLElement | null = null
        if (bindMode === "parent") {
            host = el.parentElement
        } else if (bindMode === "grandparent") {
            host = el.parentElement?.parentElement ?? null
        } else if (bindMode === "shared-parent") {
            let curr: HTMLElement | null = el.parentElement
            while (curr && curr !== document.body) {
                if (curr.children.length > 1) {
                    host = curr
                    break
                }
                curr = curr.parentElement
            }
        } else if (bindMode === "selector" && customSelector) {
            host = document.querySelector(customSelector) as HTMLElement | null
        }

        if (!host) return

        // 2. Intercept click / navigation trigger
        const handleClick = (e: MouseEvent) => {
            // Locate the shared source element inside the clicked card
            const fromElement = (host?.querySelector(sharedSelector) || host) as HTMLElement

            if (!fromElement) return

            // Prevent immediate default hard page refresh if it's an anchor tag
            if ((e.target as HTMLElement).closest("a")) {
                e.preventDefault()
            }

            // 3. Trigger animateView
            const vTransition = animateView(async () => {
                // Update browser URL & history
                window.history.pushState({}, "", targetUrl)
                window.dispatchEvent(new PopStateEvent("popstate"))

                // Yield to allow Framer/React hydration of new view
                await new Promise((resolve) => requestAnimationFrame(resolve))

                // Locate the target shared element on the newly rendered page
                const toElement = document.querySelector(sharedSelector) as HTMLElement | null
                if (fromElement && toElement) {
                    vTransition.add(fromElement, toElement)
                }
            }, transition)

            // 4. Choreograph non-shared elements (crossfade, blur, slide up)
            vTransition
                .old({
                    opacity: 0,
                    filter: `blur(${blurAmount}px)`,
                    y: -slideDistance,
                })
                .new({
                    opacity: 1,
                    filter: "blur(0px)",
                    y: 0,
                })
        }

        host.addEventListener("click", handleClick)
        return () => {
            host?.removeEventListener("click", handleClick)
        }
    }, [isClient, isOnCanvas, enabledOnCanvas, bindMode, customSelector, sharedSelector, targetUrl, blurAmount, slideDistance, transition])

    // On Canvas: Render a visible helper pill; on Published site: zero-size invisible container
    if (isOnCanvas) {
        return (
            <div
                ref={containerRef}
                style={{
                    display: "flex",
                    alignItems: "center",
                    justifyContent: "center",
                    padding: "4px 8px",
                    background: "rgba(0, 102, 255, 0.12)",
                    border: "1px dashed #0066FF",
                    borderRadius: 6,
                    fontSize: 10,
                    fontFamily: "monospace",
                    color: "#0066FF",
                    pointerEvents: "none",
                    whiteSpace: "nowrap",
                }}
            >
                Shared Transition [{bindMode}]
            </div>
        )
    }

    return (
        <div
            ref={containerRef}
            style={{
                width: 0,
                height: 0,
                position: "absolute",
                top: 0,
                left: 0,
                pointerEvents: "none",
                opacity: 0,
                visibility: "hidden",
            }}
        />
    )
}

addPropertyControls(SharedElementPageTransition, {
    targetUrl: {
        type: ControlType.String,
        title: "Target URL",
        defaultValue: "/blog/new-item",
    },
    bindMode: {
        type: ControlType.Enum,
        title: "Bind Mode",
        options: ["parent", "grandparent", "shared-parent", "selector"],
        optionTitles: ["Parent", "Grandparent", "Shared Parent", "Custom Selector"],
        defaultValue: "parent",
    },
    customSelector: {
        type: ControlType.String,
        title: "Selector",
        placeholder: "#my-card-id",
        hidden(props) {
            return props.bindMode !== "selector"
        },
    },
    sharedSelector: {
        type: ControlType.String,
        title: "Shared Target",
        defaultValue: "[data-shared-element]",
        description: "Attribute or class on the elements that should morph together.",
    },
    blurAmount: {
        type: ControlType.Number,
        title: "Blur (px)",
        min: 0,
        max: 32,
        step: 1,
        defaultValue: 8,
    },
    slideDistance: {
        type: ControlType.Number,
        title: "Slide (px)",
        min: 0,
        max: 100,
        step: 2,
        defaultValue: 20,
    },
    transition: {
        type: ControlType.Transition,
        title: "Transition",
        defaultValue: {
            type: "spring",
            stiffness: 350,
            damping: 30,
            mass: 0.9,
        },
    },
    enabledOnCanvas: {
        type: ControlType.Boolean,
        title: "Preview Canvas",
        defaultValue: false,
    },
})
```

## 6. Code Override Counterpart

For projects preferring Framer Code Overrides over Canvas Code Components:

```typescript
import type { ComponentType } from "react"
import { useEffect, useRef } from "react"
import { animateView } from "framer-motion"

/**
 * @framerDisableUnlink
 */
export function withSharedElementTransition(Component): ComponentType {
    return (props) => {
        const ref = useRef<HTMLElement | null>(null)

        const handleClick = (e: React.MouseEvent) => {
            const fromEl = ref.current
            const targetUrl = props.targetUrl || "/blog/new-item"
            const sharedSelector = "[data-shared-element]"

            if (!fromEl) return

            const transition = animateView(async () => {
                window.history.pushState({}, "", targetUrl)
                window.dispatchEvent(new PopStateEvent("popstate"))
                await new Promise((r) => requestAnimationFrame(r))

                const toEl = document.querySelector(sharedSelector) as HTMLElement | null
                if (fromEl && toEl) {
                    transition.add(fromEl, toEl)
                }
            }, {
                type: "spring",
                stiffness: 320,
                damping: 28,
            })

            transition
                .old({ opacity: 0, filter: "blur(8px)", y: -20 })
                .new({ opacity: 1, filter: "blur(0px)", y: 0 })
        }

        return (
            <div ref={ref as any} onClick={handleClick} style={{ display: "contents" }}>
                <Component {...props} />
            </div>
        )
    }
}
```

## 7. Critical Pitfalls & Checklist

1. **Hydration & SSR Safety**: Always gate `window`, `document`, and `history` calls behind `useEffect` or `isClient` checks to prevent SSR hydration mismatches in Framer.
2. **DOM Snapshot Timing**: Allow one animation frame (`requestAnimationFrame`) inside the `animateView` update callback for React to mount the destination view before querying `toElement`.
3. **Viewport Coordinate Space**: `animateView().new()` operates on viewport snapshot layers. Avoid adding manual `window.scrollX` / `window.scrollY` offsets when styling snapshots.
4. **Stable Element Markers**: Use distinct, stable attributes like `data-shared-element="card-image"` rather than generated Framer class names (e.g. `framer-1x9a...`) which shift across builds.
5. **No CSS `transition` Clash**: Avoid setting CSS `transition: all ...` on the shared elements, as it will fight Framer Motion's imperative snapshot interpolation.
