**Live Site**: `https://happier-anything-775440.framer.app`  
**Component**: `HTMLTexture3D.tsx` (`/framer/test/HTMLTexture3D.tsx` & Framer Session Code Component `HTMLTexture3D.tsx`)  
**Library**: `three-html-render` (WICG HTML-in-Canvas polyfill) & Three.js 0.186.0  
**Date**: September 24, 2026  
**Status**: Resolved, Deployed, and Verified in Production

## 1. Executive Summary

When inspecting `https://happier-anything-775440.framer.app`, the 3D interactive card appeared to fail loading its texture, rendering either transparent empty space or faint unstyled text fragments.

Deep-dive bytecode analysis of `three-html-render@0.1.2` (`dist/polyfill.mjs`), Framer's scoped CSS compiler, and headless browser pixel inspection revealed the root cause:
1. **Framer Scoped CSS Isolation**: Framer prefixes every stylesheet rule with the ancestor frame scope (e.g. `.framer-rKmX8 .framer-1up1sfh`, `.framer-rKmX8 .framer-1mdj2u9`).
2. **Polyfill SVG ForeignObject Isolation**: `three-html-render` rasterizes elements by serializing the clone into an SVG `<foreignObject>`. The polyfill's internal wrapper generation function (`he(e, t)`) wraps the element inside `<div class="${canvas.className}">`.
3. **The Scoping Disconnect**: The `<canvas>` element was instantiated with no class name (`canvas.className = ""`). Inside the polyfill's SVG document, no parent element possessed the `.framer-rKmX8` scope. Consequently, **100% of Framer's CSS rules failed to match the cloned element**, stripping the card of its `background-color: rgb(19, 19, 31)`, `border-radius: 20px`, `padding: 28px`, and flex layout. The resulting texture was 95.4% transparent (`rgba(0, 0, 0, 0)`), causing Three.js's `transparent: true` material to render the card surface completely invisible.

By programmatically walking the ancestor DOM tree from `targetEl` to `document.body` and propagating the ancestor classes (`framer-wgjo8b framer-rKmX8 framer-72rtr7`) to `<canvas>` and the polyfill's host element (`[data-html-in-canvas-host]`), as well as backing computed styles to `cloneNode.style`, the SVG foreignObject successfully evaluates all scoped Framer CSS rules. Real browser instrumentation confirms that **129,957 active card pixels** are rendered on the 3D mesh with exact dark surface tones (`rgb(19, 19, 31)`), badge geometry (`rgb(16, 39, 64)`), and crisp typography (`rgb(255, 255, 255)`).

## 2. Technical Root Cause Breakdown

### Root Cause 1: Framer Scoped CSS Architecture
Framer isolates styles using hierarchical selectors to prevent collisions:
```css
/* Generated by Framer Compiler */
.framer-rKmX8 .framer-1up1sfh {
  background-color: rgb(19, 19, 31);
  border-radius: 20px;
  padding: 28px;
  display: flex;
  flex: 0 0 auto;
  flex-flow: column;
  height: 380px;
  width: 340px;
}
```
Every element inside the card (`CardBadge`, `CardBody`, `RichTextContainer`) depends on an ancestor carrying `.framer-rKmX8`.

### Root Cause 2: Polyfill SVG Parent Wrapping in `three-html-render`
Inside `three-html-render/dist/polyfill.mjs`, the SVG serialization helper is implemented as:
```javascript
function he(e, t) {
  let o = e.parentElement,
      n = o?.getAttribute("class") || "",
      s = o?.clientWidth || e.clientWidth || e.offsetWidth,
      i = o?.clientHeight || e.clientHeight || e.offsetHeight;
  return `<html xmlns="http://www.w3.org/1999/xhtml" style="margin:0;padding:0;background:transparent !important;"><body style="margin:0;padding:0;background:transparent !important;"><div xmlns="http://www.w3.org/1999/xhtml"${n ? ` class="${we(n)}"` : ""} style="position:relative;width:${s}px;height:${i}px;margin:0;padding:0;">` + t + "</div></body></html>";
}
```
When `cloneNode` is appended to `canvas`, `e.parentElement` is the `<canvas>` DOM element.
Because `canvas.className` was empty, `n` was `""`. The resulting SVG foreignObject structure was:
```html
<svg>
  <foreignObject>
    <html>
      <body>
        <div style="position:relative;...">
          <!-- Clone is placed here with NO .framer-rKmX8 ancestor -->
          <div class="framer-1up1sfh" data-framer-name="Card">...</div>
        </div>
      </body>
    </html>
  </foreignObject>
</svg>
```
Without `.framer-rKmX8` above `.framer-1up1sfh`, the CSS engine ignored the stylesheet rule. The background color defaulted to `rgba(0, 0, 0, 0)`.

### Root Cause 3: Alpha Transparency Multiplication in Three.js
In `HTMLTexture3D.tsx`:
```typescript
const material = new THREE.MeshStandardMaterial({
    map: texture,
    roughness: numRoughness,
    metalness: numMetalness,
    transparent: true,
})
```
When the texture loaded, 123,244 out of 129,200 pixels had `alpha = 0`. With `transparent: true`, Three.js rendered every transparent pixel completely see-through, leaving only faint 1px letterforms suspended over nothingness.

## 3. Engineering Fixes Implemented

### 1. Ancestor Scope Collection & Propagation
In `/framer/test/HTMLTexture3D.tsx`:
```typescript
// Collect ancestor classes so scoped Framer CSS rules (.framer-rKmX8 .framer-1up1sfh, etc.)
// match inside the polyfill's generated SVG foreignObject wrapper
const ancestorClasses: string[] = []
let anc: HTMLElement | null = targetEl.parentElement
while (anc && anc !== document.body) {
    if (anc.className && typeof anc.className === "string") {
        ancestorClasses.push(anc.className)
    }
    anc = anc.parentElement
}
const combinedAncestorClasses = ancestorClasses.join(" ")
if (combinedAncestorClasses) {
    canvas.className = combinedAncestorClasses
    const host = document.querySelector("[data-html-in-canvas-host]") as HTMLElement | null
    if (host) {
        host.className = combinedAncestorClasses
    }
}
```

### 2. Computed Style Baseline Synchronization
Computed styles from `targetEl` are directly assigned to `cloneNode.style` to provide an immutable guarantee for critical visual properties:
```typescript
const targetComputed = window.getComputedStyle(targetEl)
if (targetComputed.backgroundColor && targetComputed.backgroundColor !== "rgba(0, 0, 0, 0)") {
    cloneNode.style.backgroundColor = targetComputed.backgroundColor
}
if (targetComputed.borderRadius) {
    cloneNode.style.borderRadius = targetComputed.borderRadius
}
```

### 3. Dynamic Host Class Guarding in Render Loop and Mutation Sync
Whenever Framer updates the DOM or re-renders, `sync()` and the 60fps render loop re-assert `host.className = combinedAncestorClasses`, ensuring the polyfill's host container and SVG generator preserve the styling scope throughout all states and viewport resizes.
